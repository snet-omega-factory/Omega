**FR**
- R6-FR1: routers register by name through the existing plugin loader (`plugins.yaml`,
  `loader: metta`). No router name appears in `src/`.
- R6-FR2: `router` unset → the null router completes the envelope with the configured
  model. There is **one** call path: the hook calls the router every time (invariant 4, O6.3).
- R6-FR3: an unknown name → startup fails, naming it and the registered names. This is a
  different message, and a different outcome, from "no router configured", which starts
  normally.
- R6-FR4: a router fills only empty fields. A non-empty `model` or `provider` it received
  comes back unchanged.
- R6-FR5: the startup log names the active router (`null` when unset).

  model. With `model="x"` → `"x"`.
- R6-T3 (rendered): R4's `off` config shows `econ-1` with the startup log naming `null`. R4's
  `bad` config shows the halt.
