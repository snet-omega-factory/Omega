**FR**
- R3-FR1: `LLMRequest` has `provider`, `model`, `router` and `metadata`, all defaulting to
  empty. A request built today's way (`llmRequest $prompt $episodes …`) has all four empty.
- R3-FR2: the effective model is `request.model` when non-empty, else the provider's
  configured model. It is computed by **one** helper and used at both raw-request sites, for
  `openai.py`'s cache key and retention branch, and for every `LLM_RAW_REQUEST`,
  `LLM_RAW_RESPONSE` and `LLM_USAGE` log line.
- R3-FR3: `openrouter.py`'s `is_anthropic` (`:49`) and `_stable_cache_key` (`:66`) use the
  effective model.
- R3-FR4: `repr(LLMRequest)` contains `provider=`, `model=` and `router=`, and leaks no
  `metadata` values that could carry user text beyond what `REQUEST:` already logs.
- R3-FR5: `request.provider` changes nothing about which provider instance is called.
